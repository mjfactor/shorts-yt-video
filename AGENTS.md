# AGENTS.md

Single-niche Shorts automation. **`story` is the only live niche** — `explainer`/`ranking` were deleted (previously parked in `deprecated_niches/`); `available_niches()` returns `['story']`; `NICHE=explainer` raises `ImportError` listing available niches.

Layout: `pipeline.py` thin entry (`NICHE` env → `niches.load_niche()` → `core.run(niche)`); **`core.py` is a single root module** (stage chain + upload + thumbnail + history + notify), importing only `niches.base`/`niches.history_migrate` (Google API libs load lazily inside `upload()`); `engine/` policy-free toolbox (TTS/FFmpeg/captions) that never imports `core` or any niche; `niches/<name>/` 3 stages. Imports flow one way (niche → engine/base); `core.py` never imports a concrete niche.

Run: Gemini script → TTS audio+timings → local-clip background → FFmpeg 1080x1920 + burned ASS captions → card thumbnail → YouTube (+ optional TikTok via Buffer). Output `out/<stamp>_short.{mp4,srt,json}` + `out/<stamp>_thumb.jpg` (stamp `%Y-%m-%d_%H%M%S`); the pipeline writes **no `.mp3`** (README's `.mp3` mention is stale); `srt` is `None` on the no-captions path.

## Commands (PowerShell — `NICHE=x cmd` does NOT work; use `$env:NICHE`)

- Full run (story default): `python pipeline.py` (needs `ffmpeg` + `ffprobe` on PATH). `pipeline.py` catches any exception, pings `core.notify_failure`, exits 1 — failure pings only fire from this entry (`demo.py` deliberately doesn't).
- Offline demo, zero API keys, never uploads, renders through the **prod stages** (`narrate()` + `build_visuals()`), skipping only content generation and upload → `out/demo_story.mp4` (+ `demo_story.srt` / `demo_story_thumb.jpg` copies from the same render): `python demo.py`; only flags are `--tts {auto,gemini,edge}` and `--words N` (there is **no** `--niche`; it errors). Uses real clips from `STORY_BG_DIR` when present, synthesizes testsrc 1080x1920 clips only when the dir is empty/missing, and hard-fails a silent render (mean volume must be > -40 dB).
- **Coverage of live code: `tools/test_reddit_card.py` (card renderer + CARD_* env precedence) and `tools/test_story_prompt.py` (prompt-contract tests)** — standalone offline unittests (`python tools/test_reddit_card.py`), no keys/network, **not run by CI**. There is **no `tests/` dir**; CI runs no tests and no lint.
- Syntax check: `python -m py_compile pipeline.py core.py demo.py get_refresh_token.py` (+ any `niches/<name>/*.py`, `engine/*.py` you touch)
- Deps: `pip install -r requirements.txt` (`edge-tts==7.2.8` pinned, `requests`, `Pillow`, `google-api-python-client`, `google-auth`, `google-auth-oauthlib`; no local transcription models)
- OAuth helper, local browser only, never CI: `python get_refresh_token.py` (needs `YT_CLIENT_ID`/`YT_CLIENT_SECRET`)
- Background prep, **manual only** (not in requirements, not in any workflow) — normalizes footage into `assets/backgrounds/bgN.mp4` (1080x1920, 30fps, cover-crop): `python tools/prep_backgrounds.py --source-folder <dir>`; `--url` uses yt-dlp (explicitly not a dependency), `--section START-END`, `--speed` (1.8), `--list` dry-run, `--force` restarts numbering
- Keyless edge-TTS render smoke through the **real** story pipeline → `out/edge_preview.mp4`: `python tools/test_edge_preview.py --card "hook line"` (extra voice/rate/pitch/BG overrides exist — see `--help`)
- Voice audition, **manual only** (not in requirements, not in CI): `python tools/voice_samples.py` renders the sample story's opening into `out/voice_samples/NN_<voice>_p<rate>.mp3` for the candidate edge voices (baselines Jenny/Andrew first) + `index.txt` (status, duration, wps); audio runs the prod edge path (synth + `_edge_single_surgery`), `--raw` skips the surgery; `--voices a,b`, `--rate`, `--pitch +6Hz`, `--words`, `--text-file`, `--out-dir` override. Rates and default pitch mirror `EDGE_RATE`/`EDGE_RATE_FEMALE` and `EDGE_PITCH`/`EDGE_PITCH_FEMALE`. Edge feature audit (what edge-tts can/can't do, Azure-only styles): `docs/edge-tts-features.md`.
- BGM provenance manifest, **manual only** (not in requirements, not in any workflow): `python tools/bgm_manifest.py sync` (merge the pool in, refresh only sha256/duration/size — human fields are preserved) / `check` (read-only audit, nonzero exit on drift) / `show` (table only); `--dir`/`--glob`/`--manifest` override the defaults.

## New-niche guide (zero core edits)

- Copy `niches/_template/` → `niches/<name>/` (discovery skips `_`-prefixed dirs) and expose a module-level `niche = <Name>Niche()` — the registry does `getattr(mod, "niche", mod)`, so the module itself is the fallback. **The template is a bit-rotted skeleton**: its `narrate` returns `duration=0.0` with `extras={"pending":True}`, its `build_visuals` returns an unwritten `workdir/short.mp4` and no srt, and it has no `load_config`/`Config`. Shape reference only, not working code.
- Exact contracts (`niches/base.py`): `Content(title, narration_text, description, tags, extras)` — **no `beats` field**; beats/queries are an `extras` convention. `NarrationResult(audio, duration, words: int, voice, style, extras)` — **`words` is an int count, not timed words**; the timed list lives in `extras["words"]`, which niche visuals consume for captions (core only logs the count during its ALIGN stage). `VisualsResult(mp4, srt, credits, used_ids, extras)`. Optional hooks: `build_metadata(...)`, `sample_content()`, `history_dedup_payload(content)` (history excerpt; core trims to a 200-char excerpt when absent), plus `load_config(name)` which `core.py` checks before falling back to a `NicheConfig` subclass scan.
- Env helpers `env_str/env_int/env_float/env_bool(name, default, prefix="NICHE_")`: prefixed non-empty → bare non-empty → default; **empty string counts as unset**. Story passes `"STORY_"` explicitly at every call site.
- Call `engine/*` helpers only, never import `core.py`; keep all knobs in config. A new niche must never hardcode a key.
- Wire-through: document vars in `.env.example` (generic + `<PREFIX>_` section), add them to `daily.yml` `env:`, and verify `NICHE=<name> python pipeline.py` — `demo.py` is story-only and cannot smoke-test a new niche.

## CI (two workflows; `daily.yml` is the pipeline)

`daily.yml` — `ubuntu-latest`, Python `3.11`, `timeout-minutes: 30`, cron **`0 6,18 * * *`** (06:00/18:00 PHT = 22:00/10:00 UTC, *not* 08:00/20:00) + `workflow_dispatch`; `concurrency.group: shorts-single`, `cancel-in-progress: false` (each run commits `history.json` back, so runs stay serial); `permissions: contents: write`. Steps: checkout default branch → setup-python → install ffmpeg → `pip install -r requirements.txt` → `python pipeline.py` → commit history → artifacts. Commit-back is `if: always()`, `git add history.json` + `chore: record short history [skip ci]` + refspec push, no-op when unchanged. Artifacts: `out/*.json` on `always()` 90d; `out/*.mp4`+`*.mp3`+`*.srt` on `failure()` 3d only. `NICHE: ${{ vars.NICHE || 'story' }}`. **CI overrides story defaults**: `STORY_TARGET_MIN` `95` (not 100 — the model writes ~430-470 words regardless; see comment), `STORY_BG_SEGMENTS` `3` (segmented BG ON; repo Variable `BG_SEGMENTS` overrides — the inline comment calls it `BGM_SEGMENTS`, a typo), `STORY_MAX_SECONDS` `130` (bare `MAX_SECONDS: 45` in the same block is inert for story — prefixed wins).

`edge-tts-smoke.yml` — manual `workflow_dispatch` only, no schedule, no commits, `permissions: contents: read`, **no concurrency block** (so it never queues behind `shorts-single`), 15min timeout; runs `tools/test_edge_preview.py` (no secrets) + a small inline evidence step, uploads `out/edge_preview.{mp4,ass,srt}` as a 7d artifact.

Secrets/vars do **not** flow automatically — every new env var needs an explicit `env:` entry, including prefixed `STORY_*` ones (bare fallbacks won't pick up a repo Variable set under the prefixed name).

## Story pipeline internals

- **The gemini TTS path is chunked (60–90 words) with a PCM cache** (`workdir/tts_cache`, sha1 over text+voice+style+speed — story passes speed 1.0) and joined **gaplessly** — `XFADE_SEC = 0.0`, not a crossfade; boundaries use `-50dB/20ms` silence trim plus `CHUNK_PAUSE_SEC` (0.10). The **edge path (default)** is one whole-script call plus offline sentence-segment surgery (pause trim, timings re-offset); sentence chunks are only a retry fallback if the single call fails.
- **Fit loop aims at 100–120s (midpoint 110) and differs by engine**: gemini → re-speed from cached PCM (factor clamped 1.05–1.25 magnitude) → one paced ±15% re-synth → sentence trim; edge (default) → up to 2 rate re-synths (`_edge_refit_rate`, clamp +0..+40%) and a far miss only records a `fit_action` string (no re-synth); both trim at the last sentence end past `MAX_SECONDS`, and edge raises if measured wps > 6.0 (truncated-audio guard).
- **Word timings differ by engine**: edge uses real `WordBoundary` service events (`_map_edge_words`); only the gemini/final-mix path falls back to proportional estimation. Do not describe both as estimated.
- Planner is pure: `total = narration.duration + 0.4`; card overlay `max(card_seconds, card_line_end + card_pad)`, fade in 0.2s / out **0.25s**. `card_pad` (0.4) is a dataclass field with **no env key**.
- **Background: one continuous local take per video by default (CI runs `STORY_BG_SEGMENTS=3`)**: `BG_DIR` is the only source, played at `BG_SINGLE_SPEED` from a random start offset (short sources loop). `BG_SELECT=rotate` (default) walks the pool in **natural** filename order keyed on `video_number` = `len(same-niche history)`, so consecutive uploads use consecutive clips and wrap; `random` shuffles. Natural order matters because plain `sorted()` puts `bg10` before `bg2`. The whole pool is rotated, not just the head, so a broken clip still falls through.
  - `BG_SEGMENTS` (local default **0 = off**) 0/1 → one continuous take, byte-for-byte the historical path. `N>=2` → the same total cut into N segments, segment `i` using `order[i % len(order)]` (the same rotate/shuffle list, **so the whole pool cycles per segment**), each with its own random start offset and identical `_seg_filter` params, then the `concat` demuxer (`-c copy`, duration-verified, re-encode fallback) back into `workdir/bg_track.mp4` — the same basename the single-take path returns, so nothing downstream knows. Segment lengths are split by whole 30fps frames so they sum to `total` (flooring would desync the 2s outro fade). `extras["segments"]` in `out/*.json` reports the **real** count (1 when off). A 1-clip pool forces the single take (warn) regardless of `BG_SEGMENTS`.
  - Either way there are no per-beat queries, no segment planner, no min_clips warning, and `credits`/`used_ids` are always `[]` — `used_ids` is contract-only. **The committed folder is the only thing CI relies on** (no fetch step).
- Empty `BG_DIR` is a hard `RuntimeError`; a clip that will not render is skipped with `::warning::` and the next is tried; when every clip fails the run stops hard. No stock-footage fallback.
- Captions burn via `ass_cwd_args(ass_path, fontsdir=...)` with `cwd=` — a bare filename avoids the Windows drive-colon, which FFmpeg parses as a filter option separator. **Never add `force_style`** (commas render as zero pixels on some builds). **No no-subs fallback on the story path** — `require_ass_filter()` raises if libass is missing.
- Dedup is per-niche: exact casefolded title or premise, else Jaccard word overlap `> 0.35` (the newest 3 entries get a tighter `> 0.22`), plus a consecutive same-skeleton guard (billed/fee family). No Gemini key → offline fallback variants ordered least-recently-used, never repeating the last. Validators raise `ValueError`; similarity regens are best-effort accept-with-warning (leaks have aired — don't trust prompt bans).
- **Word budget is history-calibrated, with a two-branch rate (`content.effective_wps`, clamp 2.5-5.5).** The **measured** rate is the median of the last 30 entries that carry both `words`+`duration` (>20 words, >10s), taken end-to-end off finished videos — currently ≈4.3 wps — so the edge rate and the overshoot are already baked in: it is used **as-is, with no edge multiplier and no overshoot** (re-applying them double-counts; a past version shipped ~130s videos). The **assumed** path (`STORY_HISTORY_WPS`, default **3.5**) multiplies `EDGE_RATE` then `LENGTH_OVERSHOOT` (1.12, clamp 1.0-1.20). **`measure_wps` returns `None`, never its default, when history has no `words`/`duration` to measure** — that `None` is load-bearing: returning 3.5 made an uncalibrated install look calibrated, the assumed branch went dead, and every draft was budgeted at 3.5 wps (~350-420 words → 71-78s videos). Entries missing either key are skipped silently.
- **Grounding is prompt-driven, cliché enforcement is hard.** `build_prompt` carries a `GROUNDED & BELIEVABLE` block (imperfect/partial payoffs, ordinary-person mechanisms, one loose thread, concrete numbers, limited narrator knowledge) and `_CLICHE_RE` in `content.py` **rejects** the cinematic reaction lines in narration only (`card_text`/`title`/`description` exempt) — e.g. "worth every penny", "looked me dead in the eye", "my blood went cold", "like nothing had happened", "priceless", "chill ran down my spine", "world turned/shattered upside down", "time froze/stopped for a moment" (order-tolerant: the inverted "for a moment, time froze" is caught too). It is a normal fixable `ValueError` reject (retry feeds `_shape_fix_prompt`), **not** a micro-accept case: already-aired stories trip it, so widen the prompt before widening the regex. No fallback variant trips it.
- `_narrator_gender` deliberately **ignores history** (history-gating once froze the voice after a failed CI push-back). Priority: `NARRATOR_GENDER_MODE=male/female` wins outright, else hard first-person regex cue → the model's own `narrator_gender` → UTC half-day clock (last-resort tiebreak for gender-neutral stories only). Cue regexes are first-person-only by design (`my fianc(e|ee|ée)`, `my husband/wife-to-be`) — never side characters or bare props.
- "Lite" is not a mode: `_model_attempts` gives any model name containing `lite` `LITE_RETRIES` drafts (clamped 1-8) vs 2 for others.

## Upload, thumbnail, history

- **Upload failure is fatal, but missing credentials are not** — no `YT_*` creds warns and skips upload (video stays in `out/`, history still recorded), yet a real upload exception propagates and records **no** history entry. `RefreshError` is fatal → re-run `get_refresh_token.py`. Only the thumbnail sequence and TikTok are warn-only.
- **The pipeline sets a custom thumbnail on every upload** (in `core.py`): the thumb is composited card-over-BG-frame (`STORY_THUMB_OFFSET_SECONDS`, default 1.0; falls back to a frame of the final mp4), then validated (exists / JPEG / <2MB), and `processingStatus == succeeded` is polled (180s timeout — an immediate `thumbnails().set` can 200-accept-then-discard), the set is retried 3×, `hasCustomThumbnail` verified, then the local file deleted. Tune with `YT_THUMB_WAIT_TIMEOUT_SEC` / `YT_THUMB_WAIT_POLL_SEC` / `YT_THUMB_VERIFY_DELAY_SEC` / `YT_THUMB_SET_RETRIES`. All warn-only.
- TikTok via Buffer (`BUFFER_API_KEY`, optional `BUFFER_TIKTOK_CHANNEL_ID`; Cloudinary host has working defaults) can never fail the run — the id is recorded as `tiktokBufferPostId`. Do not add cookie/`sessionid` uploaders.
- `history.json` is committed in the GROUPED shape `{"story": [...]}`; `save_history` always writes through `migrate_history`, `load_history` accepts a legacy flat list and migrates on load best-effort and silently. `HISTORY_KEEP = 110` is a **global flat cap** on both load and save, then regrouped. Never hand-reformat the file.
- Entry keys actually written: `date`, `title`, `niche`, `tags` (≤10), `narration`, `videoId`, `tiktokBufferPostId` (may be `null`), `used_ids`, `words` (int) + `duration` (seconds, final narration result — the only feed for story's `measure_wps`), plus story's `premise`/`key_words`/`skeleton` from `history_dedup_payload` (**`narration` is now a ≤200-char premise excerpt, not the script** — old full-script entries stay on disk and keep deduping), and `topic`, `topic_source`, `topicSource`, `category`, `narratorGender` when present. `genre`/`items` are never written — `history_fields()` in `niches/story/content.py` is **dead code** (nothing calls it).
- `niches/history_migrate.py` (`migrate_history`, `flatten_history`, `duplicate_reason`) is pure, lossless (unknown per-entry keys survive a round-trip), and the only sanctioned way to change the on-disk shape.

## Graceful degradation (do not break)

- No YouTube creds → skip upload, keep the video in `out/`. `notify_failure()` never raises.
- `retry()` (`core.py`, used by upload/Buffer) retries 429/408/5xx and no-status, other 4xx fail fast. A second `retry` lives in `engine/ffmpeg_utils.py` — don't confuse them.
- No BGM pool → synthesized drone bed (priority: explicit `BED_PATH` → pool dir → repo-root legacy glob → drone).
- The BGM pool carries a **committed provenance manifest** (`assets/background-musics/bgm_manifest.json`); `claimed: true` (`disabled` is a synonym) blacklists a track from `_pick_bgm`. A missing/malformed manifest degrades to "no blacklist", an unmanifested file is still a candidate, and a manifest that excludes *everything* is ignored with a `warn()` — it must never mute the bed. The bed loops at unity and `bgm_volume` sets the between-sentence level (an extra gain once made the bed inaudible).
- `log()`/`warn()`/`err()` emit `::warning::`/`::error::` and route through `_print`, which survives Windows cp1252 vs emoji.

## Gotchas

- The edge-TTS CLI `--flag=value` rule (bare `-10%` misparses as a new flag) is **stale for story** — it uses the `edge_tts` library, not the CLI.
- `edge-tts` is pinned `==7.2.8`, and `engine/edge_tts_client._install_endpoint_shim` patches the library's dead `speech.platform.bing.com` host to `api.msedgeservices.com` in **both** `edge_tts.constants` and `edge_tts.communicate` (communicate does `from .constants import WSS_URL`); the shim no-ops once upstream ships the fix. Don't bump/unpin casually.
- Before raising `TARGET_MAX`/`MAX_SECONDS`, verify the current YouTube Shorts ceiling (story `config.py` notes ~3 min for vertical uploads); don't assume ≤60s.
- The segmented BG path concatenates with the `concat` demuxer run from `cwd=workdir` writing **bare relative filenames** with `-safe 1`. Absolute paths would need Windows quote-escaping and `-safe 1` rejects drive letters outright — do not "fix" that back to `-i <abs path>`.
- Docstrings/comments have bit-rotted in places (README still lists `.mp3` outputs; `.env.example` stale commented defaults listed above). **Trust code + `daily.yml` over prose** — then fix the prose, never the reverse.
